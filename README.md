# Viaggi da Firenze — dati pubblici

Questo repository contiene **solo** `mete-extra.json`: le destinazioni
aggiunte all'app «Viaggi da Firenze» dopo il documento originale, già
approvate. L'app (PWA e versione a file unico) lo scarica una volta al
giorno da:

```
https://raw.githubusercontent.com/mydrinkssrl/viaggi-dati/main/mete-extra.json
```

Il codice dell'app, il documento sorgente e lo schema dei dati
(`data/METE-EXTRA.md`) vivono nel repository privato `mydrinkssrl/errore`.
Le mete nuove vengono proposte lì dalla Routine settimanale e arrivano qui
solo dopo l'approvazione. Non modificare questo file a mano: alla
sincronizzazione successiva verrebbe sovrascritto.
